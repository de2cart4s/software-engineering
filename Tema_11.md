## Лабораторная работа №2
### Класс итератор с гибкой настройкой и удобным применением 

```python
class CountDown:
    def __init__(self, start):
        self.count = start + 1

    def __iter__(self):
        return self
    
    def __next__(self):
        self.count -= 1
        if self.count < 0:
            raise StopIteration
        return self.count
    
if __name__ == '__main__':
    counter = CountDown(5)
    for i in counter:
        print(i)
```

def countdown(count):
    while count >= 0:
        yield count
        count -= 1

if __name__ == '__main__':

## Самостоятельная работа №1
### Вас никак не могут оставить числа Фибоначчи, очень уж они вас заинтересовали. Изучив новые возможности Python вы решили реализовать программу, которая считает числа Фибоначчи при помощи итераторов. Расчет начинается с чисел 1 и 1. Создайте функцию fib(n), генерирующую n чисел Фибоначчи с минимальными затратами ресурсов. Для реализации этой функции потребуется обратиться к инструкции yield (Она не сохраняет в оперативной памяти огромную последовательность, а дает возможность “доставать” промежуточные результаты по одному). Результатом решения задачи будет листинг кода и вывод в консоль с числом Фибоначчи от 200.

```python
def fib(n):
    a, b = 1, 1
    for _ in range(n):
        yield a
        a, b = b, a + b


fib_200 = None
for i, value in enumerate(fib(200), start=1):
    if i == 200:
        fib_200 = value
        break

print("200-е число Фибоначчи:", fib_200)
```

## Выводы
Что было сделано
- Была создана функция-генератор fib(n), которая выдаёт по одному элементу последовательности Фибоначчи, начиная с 1 и 1
- Для генерации используется конструкция yield, позволяющая не хранить всю последовательность в памяти.
- С помощью генератора было получено 200-е число Фибоначчи.

Как работает программа:
- Генератор fib(n) при каждом вызове yield возвращает очередное число последовательности и «замораживает» своё состояние.
- При следующем обращении вычисления продолжаются с того же места, что экономит память и ресурсы — в отличие от списка, программа хранит только два последних числа.
- Чтобы получить 200-е число, генератор перебирается в цикле, и при достижении элемента №200 значение выводится на экран.

Результат
- В консоль было выведено 200-е число Фибоначчи.
- Генератор корректно отработал, и последовательность была вычислена без использования больших объёмов памяти.

def fib(n):
